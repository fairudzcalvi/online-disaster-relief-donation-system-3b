# BayanihanRelief - Online Disaster Relief Donation System

## Description

**BayanihanRelief** is a web-based disaster donation management system that facilitates easy and secure donations for disaster relief efforts. The system features a modern public interface and an admin panel for managing donations, donors, and distributions.

## Setup Instructions

1. Install [XAMPP](https://www.apachefriends.org/) and start Apache + MySQL
2. Copy this project folder into `C:\xampp\htdocs\`
3. Open phpMyAdmin at `http://localhost/phpmyadmin`
4. Create a database named `bayanihan_relief`
5. Import `bayanihan_relief.sql`
6. Copy `api/config/database.php.example` to `api/config/database.php` and update credentials if needed
7. Open `http://localhost/your-folder-name` in your browser

> Default local DB credentials are `root` with no password (standard XAMPP setup).
